# brunosouzas: project context

## Purpose

GitHub profile repository: its README is the page shown on github.com/brunosouzas. It carries the brand of brunosouzas.com (banner, avatar, category icons) and links to the site and to the code behind each article.

Stack: Markdown, SVG, Python 3 (standard library only, `unittest`), GitHub Actions

## Technology declarations

No dependency manifest: the scripts use only the Python standard library. The workflows run `python3` from the `ubuntu-latest` runner; locally any Python 3.10+ works.

## Layout and operation sources

- [README.md](README.md): the profile page. The block between `<!-- articles:start -->` and `<!-- articles:end -->` is generated; do not edit it by hand.
- `assets/site/`: copies of `public/images/home/` from the brunosouzas.com repository. Refresh them by copying again when the site artwork changes; never edit them here.
- `assets/*.svg`: generated by `python3 scripts/build_assets.py` from `assets/site/`. Change the script, not the output.
- `scripts/update_articles.py`: rewrites the latest-articles block from `https://brunosouzas.com/rss.xml`.
- `tests/`: `python3 -m unittest discover -s tests`.
- `.github/workflows/checks.yml`: on pull requests and on `main`, runs the tests and fails when `assets/` is not what the script builds.
- `.github/workflows/latest-articles.yml`: daily (and on demand), refreshes the article list and commits to `main` only when it changed.
- `techDocs/`: Backstage TechDocs for `catalog-info.yaml`.

GitHub images in the README go through `<img>`: every SVG must be self-contained (no external references, no CSS, no scripts, fixed colours). Light and dark variants are switched with `<picture>` and `prefers-color-scheme`.

GitHub default branch inspected on 2026-10-06: `main`. Release bases are defined by the project sources, separately from that setting. Build/publish commands mentioned by those sources are context, not authorization.
