# brunosouzas: project context

## Purpose

GitHub profile repository: its README is the page shown on github.com/brunosouzas. It has three parts, all in the brand of brunosouzas.com (the v2 identity of the design system `@brunosouzas/design-system`): the header (the site's home banner), the latest articles as a list (cover thumbnail beside the title, date and description, as the site lists them), and the "Find me" buttons. Anything else lives on the site.

Stack: Markdown, SVG, Python 3 (standard library only, `unittest`), GitHub Actions
Delivery: A live
Integration branch: `main`
Trivial: none
Deliver and verify: GitHub shows `main` on the profile at once; verify that the `checks.yml` run on `main` is green and https://github.com/brunosouzas shows the change

## Technology declarations

No dependency manifest: the scripts use only the Python standard library. The workflows run `python3` from the `ubuntu-latest` runner; locally any Python 3.10+ works.

## Layout and operation sources

- [README.md](README.md): the profile page. The block between `<!-- articles:start -->` and `<!-- articles:end -->` is generated; do not edit it by hand.
- `assets/site/`: copies of files from the brunosouzas.com repository: from `public/images/home/` (`avatar.svg`, `social-linkedin*.svg`, `social-email*.svg`), and `assets-src/og/og-en.svg`, the source of the site's share image (`/og.image.png`). Refresh them by copying again, byte for byte, when the site artwork or its share image changes; never edit them here.
- `assets/*.svg`: the header and the buttons, generated by `python3 scripts/build_assets.py` from `assets/site/`. Change the script, not the output.
  - The header is the site's share image (`og-en.svg`, 1200x630), unchanged: the slogan "Code that runs for the problem you have." in Source Serif 4, the symbol, the four category badges and the signature. The slogan is text in a face embedded in the image (the `@font-face` exception below); the README's alt text carries the name and the slogan.
  - The buttons follow the site's `.btn-primary` (All articles) and `.btn-outline-primary` (the Find me links) with the design system's colours (`brand.<theme>` tokens: ink `#121212` on white, `#F1EEE8` on `#1D1C1A` in dark, one accent `#E04E17`/`#FF7A45`) and `radius.pill`. Their words are outlines (paths) in Source Sans 3 Bold, drawn by `scripts/glyphs.py` from `fonts/SourceSans3-Bold.ttf`: an SVG shown through `<img>` cannot load a web font, and these files carry no CSS.
- `fonts/`: `SourceSans3-Bold.ttf` and its `OFL.txt`, unmodified copies of the design system's `fonts/` (0.9.1). Refresh by copying; never edit.
- `assets/articles/`: one rounded cover thumbnail per latest article, generated by `python3 scripts/update_articles.py` from `https://brunosouzas.com/rss.xml`, which also writes the list in the README. The script needs each feed item's cover as `media:content` (added to the site by brunosouzas.com change `rss-item-cover`), downloads it, refuses covers that would not render through `<img>`, and removes the thumbnails of articles that left the list.
- `tests/`: `python3 -m unittest discover -s tests`.
- `.github/workflows/checks.yml`: on pull requests and on `main`, runs the tests and fails when `assets/` is not what the script builds.
- `.github/workflows/latest-articles.yml`: refreshes the list and thumbnails and commits to `main` only when they changed. It runs when the site is published (both site pipelines, in brunosouzas.com and brain, send a `repository_dispatch` of type `site-published` after the Cloudflare deploy, with the secret `GITHUB_PROFILE_DISPATCH_TOKEN` from the Azure variable group `vg-40-app-brunosouzas-com-prod`: a fine-grained token for this repository only, Contents read and write, valid one year), daily at 06:17 UTC as a safety net, and on demand from `main`. When the token expires the publish step only warns; renew it and update the variable.

The repository holds only what the README uses or what builds and checks it; remove a file when nothing uses it any more.

GitHub images in the README go through `<img>`: every SVG must be self-contained (no external references, no scripts, fixed colours, no CSS). One exception, checked by `problems()` in `scripts/build_assets.py`: a `<style>` that holds only `@font-face` rules whose every `url()` is a `data:font/` URL. The site's v2 covers carry their face that way (the design system's ADR 0008, "Type inside the image"), and an embedded font renders through `<img>`; without the exception `update_articles.py` would refuse every v2 cover. The buttons this repository draws carry no CSS; the header keeps the share image's embedded face. Light and dark variants are switched with `<picture>` and `prefers-color-scheme`.

GitHub default branch inspected on 2026-10-06: `main`. Release bases are defined by the project sources, separately from that setting. Build/publish commands mentioned by those sources are context, not authorization.
